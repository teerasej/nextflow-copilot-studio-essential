
# Check Environment

## คำแนะนำทีละขั้นตอนสำหรับการเข้าสู่ระบบ Copilot Studio portal

1. เปิดเว็บเบราว์เซอร์ของคุณ แล้วไปที่ [Copilot Studio portal](https://copilotstudio.microsoft.com/)

2. คลิกปุ่ม **Sign in** ที่มุมขวาบนของหน้าเว็บ

3. กรอกอีเมลและรหัสผ่าน Microsoft Account ของคุณ แล้วคลิก **Next** เพื่อเข้าสู่ระบบ

## คำแนะนำทีละขั้นตอนสำหรับการสลับ Environment

1. หลังจากเข้าสู่ระบบสำเร็จ ให้สังเกตที่มุมขวาบนของหน้าเว็บ จะเห็นชื่อ Environment ปัจจุบัน (เช่น "Default environment")

2. คลิกที่ชื่อ Environment นั้น จะมีรายการ Environment ทั้งหมดที่คุณมีสิทธิ์เข้าถึงแสดงขึ้นมา

3. เลือก Environment เป้าหมายที่ต้องการใช้สำหรับการทำ exercise ถัดไป (เช่น "copilot-workshop" หรือชื่อที่กำหนดไว้)

4. รอให้หน้าเว็บโหลด Environment ใหม่จนเสร็จสมบูรณ์ จากนั้นตรวจสอบให้แน่ใจว่าชื่อ Environment ที่เลือกแสดงอยู่ที่มุมขวาบน

> **Tip:** หากไม่พบ Environment ที่ต้องการ ให้ตรวจสอบสิทธิ์การเข้าถึง หรือรีเฟรชหน้าเว็บอีกครั้ง

เมื่อดำเนินการครบทุกขั้นตอนแล้ว คุณก็พร้อมสำหรับ exercise ถัดไป
