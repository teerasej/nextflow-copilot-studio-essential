# 🤖 Microsoft Copilot Studio – Practice Exercises

Welcome to this hands-on learning repository for **Microsoft Copilot Studio**!  
This collection of exercises is designed to help you **create your own AI Agents** step by step — from **beginner** to **intermediate** level.

---

## 🎯 Goal of This Repository

This repository aims to help learners **build practical skills with Microsoft Copilot Studio** through guided, real-world exercises.

By completing the exercises, you will learn to:

1. Understand the **core concepts** of Copilot Studio — Topics, System Prompts, and Entities.  
2. **Design, build, and test** your own AI Agents with clear conversation flows.  
3. Practice integrating **Power Automate**, **Dataverse**, and other data connectors.  
4. Progress from simple question-answer bots to **multi-skill, business-ready Copilots**.  
5. Apply **best practices for prompt design** and conversational AI structure.

---

## 🧩 Learning Path Overview

| Level | Focus | What You’ll Build |
|:------|:------|:------------------|
| 🟢 Beginner | Understanding Copilot Studio basics | Create your first greeting and Q&A Copilot |
| 🟡 Intermediate | Adding logic and data interaction | Build an AI Agent that connects to Power Automate or Dataverse |
| 🔵 Advanced Practice | Combining multiple skills | Design a use-case-driven Copilot (e.g., Leave Request or Customer Support Assistant) |
